HOW TO INSTALL

1

Install SuperBLT

Ensure you have SuperBLT installed in PAYDAY 2.

2

Place in Mods Directory

Extract the mod folder directly into your game's mods/ directory:

PAYDAY 2/mods/Sapphire+/
3

Configure In-Game

Go to Options > Mod Options > Sapphire+ Options to customize your settings.
